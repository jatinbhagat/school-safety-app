# Demo Sample Images

This directory contains sample images used in demo mode for the "Attach Sample Image" feature on the kiosk.

## Usage

In demo mode, when users click "Attach Sample Image" on the kiosk, a random image from this directory is selected as a placeholder attachment.

## Image Files

Add sample images here:
- `sample-image-1.jpg` - Generic classroom/hallway scene
- `sample-image-2.jpg` - School cafeteria scene
- `sample-image-3.jpg` - Playground/outdoor scene

## Requirements

- **Format:** JPG, PNG
- **Size:** < 2MB per image
- **Content:** Non-identifying, generic school scenes
- **Privacy:** NO real student faces or identifying information
